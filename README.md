# WEEK 01 – INTRODUCTION TO PROGRAMMING

## Course Information

* **Course:** COS 201 – Programming I
* **Week:** 01
* **Programming Language:** Java
* **Topic:** Introduction to Programming

## Overview

Week 01 introduces the basic concepts of programming and helps students understand how computers use instructions to perform tasks.

It serves as a foundation for learning Java programming and developing problem-solving skills.

## Practical Exercise

### FirstProgram.java

This practical introduces writing and executing a basic Java program.

The program displays:

* Course information.
* Programme of study.
* Reasons programming is useful.
* Personal learning goals.

## Concepts Practised

1. Introduction to programming.
2. Basic Java program structure.
3. Displaying output using `System.out.println()`.
4. Writing and saving Java source files.
5. Compiling and running Java programs.

## How to Compile and Run

Open the terminal inside the `week01` folder.

Compile the program:

```bash
javac FirstProgram.java
```

Run the program:

```bash
java FirstProgram
```

## Expected Learning Outcomes

By completing this practical, students should be able to:

* Understand the basic meaning of programming.
* Identify the importance of programming.
* Write a simple Java program.
* Display information on the console.
* Compile and execute a Java program.
