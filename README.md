# WEEK 01 – INTRODUCTION TO PROGRAMMING

## Course Information

* **Course:** COS 201 – Programming I
* **Week:** 01
* **Programming Language:** Java
* **Topic:** Introduction to Programming

## Overview

Week 01 introduces the basic concepts of programming and helps students understand how computers use instructions to perform tasks.

It serves as a foundation for learning Java programming and developing problem-solving skills.

## Practical Exercise

### FirstProgram.java

This practical introduces writing and executing a basic Java program.

The program displays:

* Course information.
* Programme of study.
* Reasons programming is useful.
* Personal learning goals.

## Concepts Practised

1. Introduction to programming.
2. Basic Java program structure.
3. Displaying output using `System.out.println()`.
4. Writing and saving Java source files.
5. Compiling and running Java programs.

## How to Compile and Run

Open the terminal inside the `week01` folder.

Compile the program:

```bash
javac FirstProgram.java
```

Run the program:

```bash
java FirstProgram
```

## Expected Learning Outcomes

By completing this practical, students should be able to:

* Understand the basic meaning of programming.
* Identify the importance of programming.
* Write a simple Java program.
* Display information on the console.
* Compile and execute a Java program.

## File Structure

```text
week01/
└── FirstProgram.java
```

**Status:** Week 01 practical completed.

# WEEK 03 – VARIABLES, DATA TYPES, EXPRESSIONS AND INPUT/OUTPUT

## Course Information

* **Course:** COS 201 – Programming I
* **Week:** 03
* **Programming Language:** Java
* **Topic:** Variables, Data Types, Expressions and Input/Output

## Overview

Week 03 introduces variables, data types, expressions, and input/output operations in Java.

The practical exercises demonstrate how to accept information from users, store values in variables, perform mathematical calculations, and display results.

The exercises also introduce the use of the `Scanner` class for receiving user input.

## Practical Exercises

### 1. SimpleCalculator.java

This program accepts two numbers from the user and performs basic arithmetic operations.

The program calculates:

* Sum (Addition).
* Difference (Subtraction).
* Product (Multiplication).
* Quotient (Division).

It also checks whether the second number is zero before performing division to prevent a division-by-zero error.

**Compile and run:**

```bash
javac SimpleCalculator.java
java SimpleCalculator
```

### 2. AverageCalculator.java

This program accepts a student's name and three examination scores.

It performs the following operations:

* Accepts the student's name.
* Accepts three scores.
* Calculates the total score.
* Calculates the average score.
* Displays the student's information and results.

**Compile and run:**

```bash
javac AverageCalculator.java
java AverageCalculator
```

### 3. ItemCost.java

This program calculates the total cost of an item based on its quantity and unit price.

The program:

* Accepts the item name.
* Accepts the quantity purchased.
* Accepts the unit price.
* Calculates the total cost.
* Displays the item details and total cost.

**Compile and run:**

```bash
javac ItemCost.java
java ItemCost
```

## Concepts Practised

1. Variables in Java.
2. Java data types.
3. Arithmetic operators.
4. Mathematical expressions.
5. User input using the `Scanner` class.
6. Displaying output using `System.out.println()`.
7. Performing calculations.
8. Basic conditional statements using `if-else`.

## Requirements

* Java Development Kit (JDK).
* Visual Studio Code or another Java code editor.
* Terminal or command prompt.

## Expected Learning Outcomes

After completing Week 03, students should be able to:

* Declare and use variables in Java.
* Identify and use basic Java data types.
* Accept input from users.
* Perform arithmetic operations.
* Use mathematical expressions.
* Display calculated results.
* Apply basic conditional statements.

## File Structure


## Conclusion

Week 03 provides practical experience in using variables, data types, expressions, and input/output operations in Java.

The three exercises demonstrate how Java can be used to solve simple real-life problems involving calculations and user input.
