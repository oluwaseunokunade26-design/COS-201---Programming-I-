# WEEK 01 – INTRODUCTION TO PROGRAMMING

## Course Information

* **Course:** COS 201 – Programming I
* **Week:** 01
* **Programming Language:** Java
* **Topic:** Introduction to Programming

## Overview

Week 01 introduces the basic concepts of programming and helps students understand how computers use instructions to perform tasks.

It serves as a foundation for learning Java programming and developing problem-solving skills.

## Practical Exercise

### FirstProgram.java

This practical introduces writing and executing a basic Java program.

The program displays:

* Course information.
* Programme of study.
* Reasons programming is useful.
* Personal learning goals.

## Concepts Practised

1. Introduction to programming.
2. Basic Java program structure.
3. Displaying output using `System.out.println()`.
4. Writing and saving Java source files.
5. Compiling and running Java programs.

## How to Compile and Run

Open the terminal inside the `week01` folder.

Compile the program:

```bash
javac FirstProgram.java
```

Run the program:

```bash
java FirstProgram
```

## Expected Learning Outcomes

By completing this practical, students should be able to:

* Understand the basic meaning of programming.
* Identify the importance of programming.
* Write a simple Java program.
* Display information on the console.
* Compile and execute a Java program.

## File Structure

```text
week01/
└── FirstProgram.java
```

# WEEK 02 – JAVA DEVELOPMENT AND FIRST PROGRAMS

## Course Information

* **Course:** COS 201 – Programming I
* **Week:** 02
* **Programming Language:** Java
* **Topic:** Java Development and First Programs

## Overview

Week 02 focuses on getting started with Java programming and writing simple Java programs.

It introduces the structure of Java programs and demonstrates how to display information using the console.

## Practical Exercises

### 1. HelloWorld.java

This practical involves writing a simple Java program that displays messages on the console.

The program demonstrates:

* Basic Java program structure.
* The `main()` method.
* Displaying output using `System.out.println()`.
* Compiling and running a Java program.

**Compile and run:**

```bash
javac HelloWorld.java
java HelloWorld
```

### 2. StudentProfile.java

This practical involves creating a simple Java program that displays student profile information.

The program displays:

* Student's name.
* Programme of study.
* Other basic student information included in the source code.

**Compile and run:**

```bash
javac StudentProfile.java
java StudentProfile
```

Remember to replace the sample student information with your own details.

## Concepts Practised

1. Java program structure.
2. The `main()` method.
3. Output statements.
4. Java source files.
5. Compiling Java programs.
6. Executing Java programs.

## Requirements

* Java Development Kit (JDK).
* Visual Studio Code or another Java code editor.
* Terminal or command prompt.

## Expected Learning Outcomes

After completing Week 02, students should be able to:

* Understand the basic structure of a Java program.
* Write simple Java programs.
* Display information using output statements.
* Compile Java source files.
* Execute Java programs successfully.
